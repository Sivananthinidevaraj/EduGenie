# 🎓 EduGenie - AI Based Learning Assistant

EduGenie is an AI-based personalized learning assistant that helps students with doubt-solving, assignment help, translation, and progress tracking. Built with AI, NLP & Python.

### 🚀 Features
- **Q&A Module:** Instant doubt solving for any subject
- **Quiz Module:** Auto-generates quizzes to test knowledge
- **Summary Module:** Summarizes long chapters into short points
- **Explanation Module:** Explains complex topics in simple language

### 🛠️ Tech Stack
- Python, AI, NLP

### 📁 Files in this Project
- main.py - Main application
- qna.py - Question & Answer
- quiz_module.py - Quiz generator
- summary_module.py - Chapter summarizer
- explanation_module.py - Topic explainer

### ▶️ How to Run
python main.py
